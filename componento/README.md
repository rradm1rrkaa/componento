# Componento

Статический демонстрационный магазин компьютерных комплектующих на HTML, CSS и JavaScript. Сборщик, npm и сервер не требуются.

## Запуск

Откройте `index.html` в современном браузере. Каталог также доступен напрямую через `shop.html`. Пользовательские данные сохраняются в LocalStorage этого браузера.

## Основные файлы

- `index.html` — главная, категории и навигация.
- `shop.html` — каталог, поиск, фильтры и карточки.
- `pay.html` — оформление локального демонстрационного заказа без данных банковской карты.
- `css/style.css` — общая тема, компоненты и адаптивные состояния.
- `js/data.js` — исходные товары и данные, явно используемые правилами совместимости.
- `js/product-images.js` — локальные изображения товаров и ссылки на страницы-источники.
- `assets/products/` — фотографии каталога; `download-manifest.json` хранит адреса изображений и страницы источников.
- `js/auth.js` — безопасное хранилище, миграция, профиль и демо-заказы; реальной регистрации нет.
- `js/app.js` — карточки, каталог, фильтры, поиск, корзина и общие действия.
- `js/compatibility.js` — независимые правила совместимости и диагностические примеры.
- `js/builds.js` — локальный подбор конфигураций по бюджету.
- `js/consultant.js` — консультант на основе локальных правил.
- `js/compare.js` — сравнение товаров одной категории.
- `js/reviews.js` — пользовательские отзывы, хранящиеся только в текущем браузере.
- `js/city.js` и `js/onboarding.js` — выбор города и пошаговое обучение.
- `js/pay.js` — локальная проверка формы и сохранение демонстрационного заказа.

## Данные и ограничения

Каталог содержит небольшую курируемую выборку отдельных моделей. Цены условные, а наличие, доставка, оплата, покупатели и рейтинги реальных клиентов не подключены. Каталог не расширен до 1000 моделей: добавлять синтетические модели и случайные характеристики означало бы выдавать ненадёжные сведения за реальные. Технические поля для совместимости заполнены только там, где правила могут их использовать; недостающие сведения показываются как неопределённость.

Для моделей каталога подобраны локальные фотографии. У видеокарт, у которых в названии не задан производитель платы, изображение показывает конкретный вариант партнёра и служит иллюстрацией; его внешний вид и размеры могут отличаться.

Заказы, корзина, город, избранное, сравнение, тема, история, сборки и локальные отзывы остаются на устройстве. Не вводите в демо настоящие платёжные реквизиты. Приложение не отправляет данные на сервер.

## Изменение каталога

Добавляйте товары в `js/data.js`, используя стабильный уникальный `id`, корректную категорию, цену в тенге и набор характеристик именно для этого типа товара. Для проверок совместимости отдельно добавляйте подтверждённые поля в `COMPONENTO_COMPAT` и соответствующее правило в `js/compatibility.js`. Не заполняйте неизвестные значения предположениями. Для подтверждённых моделей можно добавить `sourceUrl`, который появится в карточке товара.

Фильтры категорий находятся в `FILTER_FIELDS` файла `js/app.js`, а кандидаты и веса подборщика — в `js/builds.js`. Схема пользовательских данных централизована в `js/auth.js`; текущая версия схемы сохраняет доступные данные прежней демо-версии и удаляет ненужные локальные учётные записи с хэшами паролей.
